Building for the Durable Web

Status: 🌲 Evergreen · Planted: March 15, 2026 · Last tended: July 20, 2026

The web's original promise was remarkably simple yet profoundly resilient: documents linked together, accessible by anyone, readable by any browser, regardless of the underlying operating system or device capabilities. It was designed to be democratic and durable. Today, however, much of the web has drifted from this foundation.

Modern web development often relies on complex frameworks, massive dependency trees, and convoluted build steps. While these tools can offer developer convenience in the short term, they introduce fragility. A site built heavily on a specific Javascript framework might break entirely if a single library deprecates, a service changes its API, or a dependency is compromised. We're building digital sandcastles that erode with the slightest shift in the technological tide.

"The web isn't broken, but our approach to building for it often is. We've traded resilience for fleeting convenience."

The case for plain HTML and CSS is stronger than ever. It's an undeniable fact of web architecture: a page written in raw HTML in 1999 still loads flawlessly in browsers today. No npm installs required, no breaking changes to fix, no Webpack configurations to debug. The fundamental technologies of the web—HTML, CSS, and vanilla JS—are designed for unparalleled backwards compatibility.

To build a durable web, we should embrace practical principles:

  • Semantic HTML: Use tags for their intended structural meaning, ensuring accessibility and machine readability.
  • Progressive Enhancement: Start with a robust, functional core that works everywhere, then layer on stylistic and interactive enhancements for capable browsers.
  • Zero Build Steps: Whenever possible, serve the files you write. Avoid compilers and bundlers for simple static content.
  • Minimal Dependencies: Rely on native browser APIs rather than external libraries. The fewer moving parts, the fewer points of failure.

This very website is an exercise in practicing what I preach. It's handcrafted, devoid of heavy frameworks, and serves content as simple text files over the network. It's not just about nostalgia; it's about creating a digital home that I know will still be standing, easily readable, a decade from now without requiring constant maintenance. A durable web is a peaceful web.
